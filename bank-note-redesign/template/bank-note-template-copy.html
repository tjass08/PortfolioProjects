Paste it into Constant Contact

  1. Open your custom code email, the screen with the numbered lines.
  2. Click anywhere inside the code window.
  3. Press Ctrl+A (Cmd+A on a Mac) to select the starter code that’s there.
  4. Press Ctrl+V (Cmd+V) to paste. The starter code is replaced. Line 1 should now read <!DOCTYPE html>, with about 125 lines below it. If the window is empty, nothing was copied, so go back and use the box above.
  5. Turn on Live Preview to see the email, then click Save.

Gray boxes are placeholder images. Swap them for your real photos and ads before sending. The README in the project folder walks through that.

Changing the words each week

  1. In the code window, find the word you want to change. Every spot in the blank template starts with “EDIT,” and every section is labeled in capitals, like 2. THE TOP STORY.
  2. Type over the words only. Leave anything inside < > brackets alone.
  3. Check Live Preview as you go. If something looks broken, press Ctrl+Z to undo.
