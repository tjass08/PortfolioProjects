# Bank Note drag-and-drop template spec

Use this to turn the modern custom-code design (`template/bank-note-sample-2026-10-08.html`) into a **drag-and-drop** Constant Contact template. In a drag-and-drop template, anyone on the team can click to change text and swap photos without touching code.

Two ways to get there:

1. **Constant Contact’s design service:** their designers rebuild the design as a branded drag-and-drop template. Send them this spec, the sample HTML file and the PDF packet.
2. **Build it yourselves:** follow the block-by-block steps below in the regular email editor, then save it as a template.

## What carries over and what doesn’t

| Design element | In drag-and-drop | How |
| --- | --- | --- |
| White page, clean type, blue accents | ✅ Yes | Email-wide styles: background, fonts, link color |
| Emoji labels and section openers | ✅ Yes | Type or paste emoji into any Text block (Windows: **Win + .**; Mac: **Ctrl + Cmd + Space**) |
| Bold lead-ins like “Why it matters:” | ✅ Yes | Bold text in a Text block |
| Pill-shaped buttons with arrows | ✅ Mostly | Button block with the corner radius set high, text ending in “→” |
| Tinted cards (Spotlight, Credit Hours, In this edition) | ✅ Mostly | Section or block background color. Rounded card corners may not be available. |
| Short blue underline under section titles | ⚠️ Close | A Divider block, set narrow and blue, or skip it |
| Date “pills” in Deadlines | ⚠️ Close | Bold date text in a Text block instead |
| Two columns that stack on phones | ✅ Yes | Two-column layout. Constant Contact stacks these on mobile automatically. |
| Rounded photo corners | ❌ Usually not | Square photos are fine |

## Email-wide settings

- **Page background:** #F1F3F6. **Email background:** #FFFFFF.
- **Font:** Arial or Helvetica (the closest web-safe match).
- **Body text:** 16 to 17 px, color #273142. **Headlines:** bold, color #111827.
- **Links and buttons:** IBA blue #0054A6. Second button color: navy #002E5D. Spotlight button: gold #B7791F.
- **Soft panel colors:** gray-blue #F4F7FB (In this edition, sign-off), light blue #E6F0FB (Credit Hours), cream #FFF8EB (Member Spotlight).
- **Preheader:** use the editor’s preheader field (drag-and-drop emails have one).

## Making it the team template

1. Build it once with real content, then **save it as a template**. Name it “Bank Note MASTER.”
2. Each week, start from the template, so the original stays untouched.
3. To keep anyone from rearranging the layout by accident, agree on one rule: edit text and swap photos, but don’t move or delete sections. The member sections and Credit Hours stay put every week.

## Questions for Constant Contact’s design service

1. Will the finished template be editable in the drag-and-drop editor, so staff click to change text and photos?
2. What does it cost, and how long does it take?
3. Can the template be copied into our IBMC and IBIS accounts, or does each account need its own?
4. Which design details from the sample (tinted cards, pill buttons, emoji labels, two-column stacking) can they match, and which can’t they?
5. Can they include saved section layouts for briefs, deadlines and webinar days, so we can add one by dragging it in?
